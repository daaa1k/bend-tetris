# Domain Docs

This repo uses a single-context layout: root `CONTEXT.md` and `docs/adr/`.

Before exploring an area, read root `CONTEXT.md` and relevant ADRs in `docs/adr/`. If either is absent, continue without flagging it.

Use domain terms from `CONTEXT.md` in issues, proposals, hypotheses, and tests. If an existing ADR conflicts with a proposal, state the conflict explicitly.
